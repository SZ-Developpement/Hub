# SZ Hub

## Phase 1 — Socle (MVP minimal)

- Auth (Better Auth, comme tes autres projets) + rôles (toi = admin, futurs membres = roles différents)
- Gestion clients : fiche client basique (nom, contact, projets associés)
- Gestion projets : statut, description, lien avec un client, dates clés
- Dashboard simple : vue d'ensemble (nb clients actifs, projets en cours)

## Phase 2 — Facturation

- Création de devis/factures liés à un projet/client
- Statuts (envoyé, payé, en retard)
- Export PDF (tu as déjà l'expérience avec @react-pdf/renderer via le CV builder)
- Vue trésorerie simple (total facturé, total payé, en attente)

## Phase 3 — Suivi projet avancé

- Timeline/jalons par projet (proche de la logique Projex que t'as déjà fait)
- Notes/journal de bord par projet
- Liens vers repos GitHub associés (intégration API GitHub, que tu maîtrises)

## Phase 4 — Équipe SZ Dev

- Gestion des membres (rôles, accès par projet)
- Attribution de tâches/projets aux membres
- Visibilité sélective (cohérent avec ton ADN "mystère/exclusivité")

## Phase 5 — Portail client (optionnel, plus tard)

- Accès restreint pour qu'un client suive l'avancement de son projet
  -Espace partagé de livrables/documents
